Member feedback · Stefan Meury · points 1 & 2

Simpler layout, consistent galleries

Recommendations for the two complaints that can be fixed without new features: the site feels complex, and the galleries look unsorted and inconsistent. Each recommendation comes from the live site as an anonymous visitor sees it, measured on 25 October 2026.

Mockups are wireframes: photo titles are real, while authors, colours and counts are placeholders. Each change is labelled Admin only when it is a Discourse setting or a staff action with no code, and Theme when it needs a change to SPC Suite.

What makes it feel complex

These are measured on the live site, not opinions. Each one matches something Stefan wrote.

1 · Simplify the layout

1.1 Show photos within the first screen on category pages

Each category page currently stacks four bands before the gallery: a 300px hero, a description box, the points leaderboard, and Discourse's filter bar. Merge the first two into one compact header, take the leaderboard off, and keep a single tab row.

  • Hero becomes one row: title, the first sentence of the category description, a "More about this category" link to the About topic, and one primary button.
  • Photo Feedback currently has two equal buttons ("Submit an image", "Submit a photo series"). Keep one, "Ask for feedback", and offer the series option inside the form. The form already steers single photos away from the project form.
  • Drop the category dropdown from the filter bar on category pages, since you are already in the category. Keep a tag filter only where tags mean something (subject in Photo Feedback, round in the Challenge).

"Needs feedback" lists photos with no critique yet. It shows the give-two-get-one rule in practice, and it is the cheapest way to surface the photos that most need a reply.

1.2 Put the leaderboard in one place

The same all-category points strip appears on every category page, between the description and the photos. It belongs to the club as a whole, not to any one category.

  • Show it on the homepage (the leaderboard_show_on_homepage setting already exists) and on the Monthly Challenge page, where competing is the point. Remove it from the other category pages.
  • This is a gate change in spc-leaderboard-strip.js (activeForUrl), not a redesign.

1.3 A homepage with three doors and two photo rows

The homepage stacks a hero, a paragraph that repeats the hero, seven category cards and one mixed feed of every category. A visitor has to read the whole page to find out where the photos are.

  • Hero: keep it, but cut the paragraph under it, which says the same thing twice.
  • Three doors for the three things people come to do: Monthly Challenge, Photo Feedback, Introduce Yourself. The other categories (Webinars, Meetups, General, Website Feedback) go in one line of plain links below.
  • Two photo rows instead of one mixed feed: "This month: Juxtaposition" (the current round's entries) and "Waiting for feedback" (newest Photo Feedback posts). Each row has a "See all →" link to its category, so nobody has to guess where a photo came from.

2 · Consistent galleries

2.1 Sort by date posted, and say so Admin only

Discourse's "Latest" means "latest activity". One new comment on an old photo moves it to the top. For a forum that is fine. For a gallery it reads as "unsorted", which is exactly what Stefan wrote.

  • In category settings → default topic list sort, set categories 6, 7 and 12 to Created, descending (newest first). This is native Discourse, with no code.
  • Then add a small "Sorted by date posted" label next to the tabs Theme, so the order is stated rather than guessed.
Trade-off for Photo Feedback: today a new critique bumps a photo back up, which is how members notice a conversation has moved. Sorted by date posted, they rely on notifications and the "Most discussed" tab for that. The Challenge and Introductions lose nothing.

2.2 Monthly Challenge: one round at a time Theme

Today October's and September's entries run together in one stream. Show the current round by default, and give every past round its own page, reached by a row of round chips.

  • Round chips above the gallery: October · Juxtaposition (current), September · Frame in Frame, August · Animals… Each links to the round's existing tag page (/tags/c/monthly-challenge/6/<slug>/<id>), so no new data or route is needed. Display names come from the round tags the theme already resolves (tagName() for the label, tagSlug() for the URL).
  • Current round: newest first, with a vote button on each card.
  • Past rounds: sorted by votes, with the winner first and marked. Each round becomes a finished, browsable gallery: the "competition gallery" Stefan could not find.
  • The round brief becomes a banner above the round's photos instead of a card mixed in with them. The "How it works" topic is already linked from the hero ("How voting works"), so unpin it from the list.

2.4 No placeholder cards Admin only

The first card in Photo Feedback, Introduce Yourself and the Challenge is a pinned text topic ("About the … category", "Here's how it works"), and it renders as a grey speech-bubble placeholder. That is the most prominent spot in every gallery.

  • Unpin the "About" topics in 7 and 12, and "Here's how it works" in 6. Each is already linked from the category header ("More about this category" or "How voting works"), so nothing becomes unreachable.
  • Keep the round brief pinned. Pinning it is how the theme knows which round is current. Recommendation 2.2 moves it into a banner, so it stops looking like a placeholder.
  • The homepage "Willkommen bei Swiss Photo Club Community!" welcome topic has the same problem in the homepage feed. Unpin it there too. Recommendation 1.3 removes that feed anyway.

Suggested order

Start with the admin-only changes. They cost nothing, can be undone in a minute, and make a good first thing to show Stefan in the call he offered.

  1. This week, admin only: set galleries to sort by date posted (2.1), unpin the About, How-it-works and welcome topics (2.4), make names consistent and remove Meetups from the nav (1.4). Then ask Stefan whether it already feels less "unsorted".
  2. Compact category header, leaderboard in one place (1.1, 1.2). This is a CSS and hero-renderer change in spc-hero.js, category-hero.scss and the leaderboard gate. It is the biggest win on phones.
  3. One card format (2.3). This is the riskiest step because of masonry, so it gets its own commit and is verified on 6, 7, 8 and 12.
  4. Challenge round chips and the past-round view (2.2). It builds on round tags the theme already resolves.
  5. Homepage doors and photo rows (1.3). It goes last because it reuses the card from step 3 and the round from step 4.

Open questions

  • Photo Feedback sort: is losing "bump on new critique" acceptable, or should Photo Feedback stay on activity order and only the Challenge and Introductions switch to date posted?
  • Cropped grid vs masonry: this document keeps masonry. If Stefan means "standardized" literally (all photos the same shape), a uniform cropped grid is possible, but it cuts off photos, which conflicts with "the photograph is the subject". Worth asking him in the call.
  • Signed-in homepage: the mockups show a signed-out visitor. For members, the hero could shrink further to "Welcome back" plus the current round.
